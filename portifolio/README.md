# Portfólio PHP

Projeto de portfólio desenvolvido em PHP + HTML + CSS.

## 🚀 Como rodar

1. Instale o XAMPP ou Laragon
2. Coloque a pasta `portifolio` dentro do `htdocs`
3. Acesse no navegador:

http://localhost/portifolio

## 💻 Tecnologias
- PHP
- HTML
- CSS

## 📌 Funcionalidades
- Apresentação pessoal
- Tags de habilidades
- Listagem de projetos dinâmica
- Seção de contato
